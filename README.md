# 日常小账 & 生活微手帐 (Daily Bookkeeping & Journal)

专为个人打造的高颜值、极简、丝滑的**日常消费记账 + 生活随记（打卡、读书、旅游漫记）**微信小程序。

采用 **Local-First Hybrid Sync（本地优先 + 微信云端静默自动双向同步）** 商业级架构：不仅断网秒开、0 延迟即时保存，还能无缝实现多设备登录与换机云端自动恢复。

---

## 🌟 核心特性

1. **高频品类与生动 Emoji 点选**：
   * 预设高频消费：🍳 早饭、🍱 午饭、🍲 晚饭、🍢 夜宵、🛒 美团小象超市、🏠 房租、💡 水电费、🛍️ 购物平台、☕ 饮品咖啡、🚖 打车交通、🍎 水果零食；
   * 支持 **`[ ➕ 自定义 ]`** 搭配 32 款精选生动 Emoji；
   * 自定义品类**自动本地持久化**（下次直接以独立卡片展示），支持长按确认删除。

2. **生活随记与习惯打卡**：
   * ⚡ **多维习惯打卡**：支持丰富 Emoji（🏃 健身、🌙 早睡、💧 8杯水、😊 好心情、🧘 冥想、🚴 骑行等），卡片底部呈现精致多彩胶囊，支持长按安全删除；
   * 📖 **读书足迹**：书名、阅读进度（如第3章 / 80%）及精选书摘心得随笔；
   * ✈️ **旅途漫记**：目的地、出行标签（周末漫游 / 避暑徒步）及风景见闻。

3. **流水账单单笔修改与删除**：
   * 点击任意账单项（如 `🍳 早饭 ¥15.00`），即可拉起专属修改弹窗；
   * 支持自由修改金额、更改品类、修改备注、平移到其他消费日期，或单笔精准删除。

4. **专业统计分析与多维走势对比**：
   * **时间维度切换**：`[ ⚡ 本周 | 📅 本月 | 📜 全部 ]`；
   * **月度二级折叠**：支持手势左右轻滑切换月份，展开月份后自动按周二级折叠（如第1周、第2周）；
   * **开销走势图**：支持按日、按周、按月对比，支持 **`[ 🕒 按时间 | 💰 按消费 ]`** 一键排序切换，同月份周柱下方自动连贯小横线；
   * **品类消费圆环饼图**（Canvas 2D）与生活打卡排行榜。

5. **微信云开发（CloudBase）实时双向同步**：
   * 绑定微信云开发环境与 `daily_bills` 集合；
   * 本地秒开秒存（0毫秒），后台防抖（1.2秒）静默同步至云数据库；
   * 跨设备登录同一微信号自动秒级恢复。

6. **智能文本导入与数据导出备份**：
   * 支持批量粘贴账单长文智能解析（自动识别品类、金额、读书、旅游与打卡）；
   * 内置跨越 6 个月的高质量测试手账数据与一键精准剔除清理工具；
   * 支持一键将全部手账以纯文本格式备份复制到剪贴板。

## 🚀 本地运行与开发调试

1. 打开 **微信开发者工具**；
2. 点击 **【导入】** 按钮，选择本项目根目录；
3. AppID 填入你自己的微信小程序 AppID；
4. 点击 **【确定】** 即可在模拟器中即时体验完整功能。
